# PDF 扫描件拆分工作台

一个面向 Windows 的本地桌面工具，用于处理厚扫描 PDF：预览页面、删除空白页、人工记录页码、按自定义命名规则拆分并导出。它适合页面内容相似、无法可靠依靠脚本或 OCR 自动判断边界的扫描材料。

## 功能

- 导入本地 PDF 并生成页面缩略图。
- 选择、删除和拖拽重排页面，支持撤销。
- 一键检测并删除空白页。
- 通过页面预览人工填写材料名称和页码范围。
- 在选项中配置材料清单、固定/变量命名片段、输出位置和右侧面板宽度。
- 导出处理后的完整 PDF，以及按页码拆分的 PDF 文件。
- 自动保存填写中的材料名称、页码和选项设置。

## 项目结构

```text
PDF扫描件拆分工作台/
├─ main.py              # 程序入口
├─ ui_app.py            # 主窗口和选项窗口
├─ page_workspace.py    # 页面预览、缩放、删除和拖拽
├─ app_state.py         # 当前会话状态
├─ pdf_engine.py        # PDF 读取、渲染和空白页处理
├─ naming_rules.py      # 命名结构和文件名处理
├─ exporter.py          # 页码校验和拆分导出
├─ config.json          # 通用示例配置
├─ requirements.txt     # Python 依赖
└─ .gitignore           # 本地文件排除规则
```

## 安装与启动

需要 Windows、Python 3.10 或更高版本。首次运行前在项目目录执行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以使用 `py main.py` 启动。当前项目以源码方式运行，尚未提供打包后的 `.exe`。

## 基本流程

1. 点击“导入”，选择需要处理的 PDF。
2. 在左侧查看页面；必要时删除空白页、删除错误页面或拖拽调整顺序。
3. 在右侧填写材料名称和页码范围。页码以当前左侧页面顺序为准。
4. 在“选项”中按需要调整命名结构、材料清单和输出位置。
5. 点击“导出”，通过校验后生成拆分结果。

默认输出到原 PDF 同级目录下的 `原文件名_拆分结果` 文件夹，原始 PDF 不会被覆盖。

支持的页码格式包括 `5`、`5-8`、`5,8-10,13`。页码超出范围、重叠、遗漏或重复使用时，程序会阻止导出并提示修正。材料名称允许暂时为空，但导出前必须完成必要填写。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Enter` | 当前页码框跳到下一行 |
| `↑` | 当前页码框跳到上一行 |
| 名称框末尾 `→` | 跳到同一行页码框 |
| 页码框开头 `←` | 返回同一行名称框 |
| 左侧页面区 `→` | 返回最近使用的页码框 |
| `Delete` | 删除选中的页面 |
| `Ctrl+Z` | 撤销页面操作 |
| `Ctrl+Enter` | 导出拆分结果 |
| `Ctrl+鼠标滚轮` | 缩放页面预览 |

## 自动保存与隐私

用户输入材料名称或页码后会自动保存；选项设置也会自动保存。保存内容不按当前 PDF 区分，不会因为导入另一个 PDF 而擅自清空或替换。默认保存到：

```text
%LOCALAPPDATA%\PDFScanSplitWorkbench\
```

仓库中的 `config.json` 只是通用示例。真实填写内容、真实 PDF、导出文件、旧版 demo 和个人作品集文档均不会随项目上传。`.gitignore` 已排除这些本地内容。

## 当前范围

本项目是本地 MVP，暂不支持 OCR/AI 自动识别、在线上传、多人协作、云端保存、裁白边、PDF 批注编辑、自动判断材料类别或 ZIP 打包。
